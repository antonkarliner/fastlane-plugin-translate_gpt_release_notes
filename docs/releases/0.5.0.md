# Release 0.5.0

Prepared on 2026-09-19. This note records the artifact, validation results, and publication procedure for version 0.5.0.

## Release notes

Version 0.5.0 adds two optional translation tools. Existing Fastfiles retain their current behavior.

- Android shortening retries: set `android_length_retries: 1` or `2` to retry OpenAI, Anthropic, or Gemini drafts that exceed 500 characters before truncation. Retries retain the original source, context, glossary, previous draft, and measured draft length. Failed or exhausted shortening falls back to truncating the shortest usable draft with a warning. The default is `0`; iOS and DeepL behavior are unchanged.
- Jev quality checks: set `jev_check: true` and configure `TYPESAFE_API_KEY` to report unsupported claims, omissions, contradictions, wrong-language sentences, and terminology errors. Checks use `jev-1.13.0`, default to a warning threshold of `0.5`, and evaluate only the final translation. Warnings and checker outages never block writes. Checks are disabled by default.
- Both tools run in dry runs, making real API requests when enabled without writing translation files or the successful-run marker.
- Syncthing conflict copies are excluded from automatic plugin loading and gem packaging. Local conflict files remain intact. The package now includes `CHANGELOG.md`.

No runtime dependencies were added. Jev uses Ruby's HTTP and JSON libraries. Translation API requests are still made by the selected provider.
